# YAZ EAT

Site vitrine + commande WhatsApp de Yaz Eat (Les Bananiers, Alger).
Site statique : index.html + assets/. Déployé sur Vercel (projet yaz_eat).

Pour changer les prix ou le menu : modifier `const MENU` dans index.html (price: 0 = prix non affiché).

L ancienne version Next.js reste dans l historique git.
