# YAZ EAT

Site vitrine + commande WhatsApp de Yaz Eat (Les Bananiers, Alger).
Site statique : index.html + assets/. Déployé sur Vercel (projet yaz_eat) à chaque push sur main.

- assets/menu/ : photos des plats (720x450 webp, même style)
- assets/video/ : vidéos courtes (540x960, sans son) + posters
- Prix et menu : `const MENU` dans index.html
